# Contributing

This repository is a read-only mirror of the `clients/podfetcher-tools` directory
in the private [podfetcher](https://github.com/FloHiwg/podfetcher) monorepo.

Code changes are made in the monorepo and automatically synced here on every merge
to `main`. Pull requests opened against this repo cannot be merged directly.

## How to contribute

1. Open an [issue](https://github.com/FloHiwg/podfetcher-tools/issues) describing
   the bug or feature request.
2. Once discussed and accepted, the change will be implemented in the monorepo
   and appear here on the next release.

## Releases

Releases are published to npm automatically when the version in `package.json`
is bumped in the monorepo.
